# Screenshot Intake

Use this when the user needs guidance on what to upload or when the analysis is based on screenshots.

## Preferred Input

Ask for one full-page screenshot of the LinkedIn profile in desktop Chrome. A full-page screenshot preserves the real section order, visual hierarchy, first-screen impression, Featured section, Activity, Experience, Skills, Recommendations, and missing sections.

If a full-page screenshot is hard to capture, ask for these section screenshots:

1. Intro/hero: banner, photo, name, headline, location, current role, buttons, contact/open-to-work/creator signals.
2. About.
3. Featured.
4. Activity/posts/comments.
5. Experience.
6. Skills.
7. Recommendations.
8. Education, licenses, certifications, projects, publications, awards, languages, volunteer sections if present.
9. Contact info/sidebar only if the user wants conversion or outreach analysis.

The user can also add a target role, job description, target buyer/investor audience, competitor profile screenshots, or their preferred tone.

## Chrome Full-Page Screenshot Steps

Give concise instructions:

1. Open LinkedIn in Chrome on desktop and go to the profile page.
2. Set browser zoom to 80-100% so the profile is readable.
3. Scroll to the top of the profile.
4. Open DevTools:
   - Mac: `Option` + `Command` + `I`
   - Windows/Linux: `Ctrl` + `Shift` + `I`
5. Open the Command Menu:
   - Mac: `Command` + `Shift` + `P`
   - Windows/Linux: `Ctrl` + `Shift` + `P`
6. Type `Capture full size screenshot` and press Enter.
7. Upload the downloaded PNG.

If the full-page capture fails because LinkedIn lazy-loads sections, tell the user to slowly scroll through the whole profile once, return to the top, and repeat the capture. If it still fails, use section screenshots.

## Section Screenshot Tips

- Use desktop screenshots, not mobile, unless the audit is specifically for mobile profile appearance.
- Keep text readable; avoid browser zoom below 80%.
- Expand "see more" in About and Experience if the user wants copy-level feedback.
- Click "Show all activity" and capture Posts and Comments if content authority matters.
- Capture the public profile view if the user cares about how non-connections see the profile.
- Blur or crop private contact details, email, phone, exact address, private messages, notifications, and other unrelated personal data.

## Screenshot Analysis Rules

- Treat screenshots as visual evidence, not complete structured data.
- Do not penalize a missing section if it may simply be outside the uploaded screenshots; mark it `Unknown`.
- Call out confidence: `High` for full-page screenshot, `Medium` for most major sections, `Low` for hero-only or partial captures.
- If text is unreadable, ask for a closer section screenshot rather than guessing.
- For profile copy rewrites, preserve only facts visible in the screenshot or explicitly supplied by the user.
