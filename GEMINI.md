# LinkedIn Profile Analyzer

Use this repository as a LinkedIn profile analysis skillset.

When the user asks to audit, rewrite, score, compare, or optimize a LinkedIn profile, follow `skills/linkedin-profile-analysis/SKILL.md`.

Use these reference files when needed:

- `skills/linkedin-profile-analysis/references/analysis-rubric.md` for scoring and prioritization.
- `skills/linkedin-profile-analysis/references/output-templates.md` for audit, rewrite, role-fit, and content-strategy outputs.
- `skills/linkedin-profile-analysis/references/ethics-and-boundaries.md` for privacy, sensitive inference, and high-impact decision boundaries.

Default behavior:

1. Identify the supplied profile material and the user's goal.
2. Analyze only observable profile content.
3. Score dimensions with enough evidence and mark missing evidence as `Unknown`.
4. Prioritize concrete profile improvements by impact.
5. Preserve factual truth when rewriting and use placeholders for unverified metrics or claims.
