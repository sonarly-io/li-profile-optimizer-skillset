# Security And Privacy

Please report security or privacy issues privately to the repository owner instead of opening a public issue.

## Data Handling Expectations

This repository contains prompts, templates, and skill instructions. It does not run a hosted service or collect data by itself.

Users may upload LinkedIn screenshots to the AI provider they choose, such as Claude or Codex. Those screenshots can contain personal data. The skill instructs users to blur private contact details and avoid uploading third-party private data.

## Out Of Scope

Do not use this skillset for:

- hiring, firing, compensation, or eligibility decisions
- credit, insurance, legal, housing, education, or other high-impact decisions
- inferring protected or sensitive traits
- fabricating credentials, metrics, endorsements, or recommendations
- scraping or bypassing LinkedIn access controls

## Reporting

Include:

- affected file or instruction
- expected safe behavior
- observed risky behavior
- suggested fix if available
