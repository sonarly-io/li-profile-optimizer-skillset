# LinkedIn Profile Analyzer Skillset

When asked to analyze, audit, rewrite, or optimize a LinkedIn profile, use the skill instructions in `skills/linkedin-profile-analysis/SKILL.md`.

Load reference files only as needed:

- `skills/linkedin-profile-analysis/references/screenshot-intake.md` when the user needs capture instructions or provides screenshots.
- `skills/linkedin-profile-analysis/references/goal-intake.md` when the user's goal or target audience is missing or ambiguous.
- `skills/linkedin-profile-analysis/references/analysis-rubric.md` for scorecards, audits, and audience-fit analysis.
- `skills/linkedin-profile-analysis/references/output-templates.md` for structured deliverables and section rewrites.
- `skills/linkedin-profile-analysis/references/html-report.md` when the user asks for a polished HTML report, dashboard, charts, or browser-openable artifact.
- `skills/linkedin-profile-analysis/references/ethics-and-boundaries.md` for sensitive, third-party, scraped, or high-stakes analysis.
- `skills/linkedin-profile-analysis/references/research-basis.md` when explaining why profile sections or metrics matter.

Prefer full-page LinkedIn profile screenshots from desktop Chrome. Ask for the user's main goal before scoring when it is not clear. If the user provides partial screenshots, score visible sections and mark missing or unreadable sections as `Unknown`. Keep analysis evidence-led. Separate observable profile communication issues from career advice, avoid sensitive inferences, and mark unverified claims with placeholders.
